
# Leche de Cabra - Sitio bilingue listo para GitHub Pages

Contenido:
- index.html (bilingue ES/EN)

- script.js (contador conectado a CountAPI)
- img/ (imágenes de ejemplo; reemplaza por fotos reales)

Instrucciones rápidas:
1. Descomprime este ZIP.
2. Sube todos los archivos a la rama `main` de tu repo y colócalos en la raíz.
3. En GitHub: Settings -> Pages -> Branch: main -> Root (/) -> Save.
4. Formulario: está conectado a Formspree (`https://formspree.io/f/mnqwyero`). Reemplaza si deseas usar otro endpoint.
5. Contador: se usa la key `lechedecabra/webvisitas` en CountAPI.
